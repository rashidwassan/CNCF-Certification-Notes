# OpenShift

- Open-source container orchestration platform by RedHat.
- Used to develop and deploy of the applications.
- It is a `platform-as-a-service` offering by RedHat.

### Flavors

1. OpenShift Origin - Open Source Application Container Platform
2. OpenShift Online - Public Application Development Hosting Service (Publicly hosted OpenShift Origin)
3. OpenShift Dedicated - Managed Private Cluster on AWS/Google Cloud.
4. OpenShift Entreprise - On-prem Private Hosting of OpenShift (Managed)

## OpenShift Origin
- Based on Docker Containers
- Uses Kubernetes cluster manager.
- OpenShift abstracts the most underlying Kubernetes functionalities
- Provides built-in SCM support, Piplelines, Registry, Software defined networking, API, Governance.


## Essential Commands:
- crc setup

- OpenShift by default uses HA Proxy as ingress controller.
